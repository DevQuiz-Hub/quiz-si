# quiz-si 🧠

Interactive self-assessment test engine for **SI (Sistemas Inteligentes / Intelligent Systems)**.

This repository contains a curated question set covering intelligent agents, knowledge representation, Semantic Web technologies, machine learning and expert systems.

Part of the DevQuiz-Hub ecosystem.

## 📚 Core Topics Covered

* **Block 1**: Intelligent agents, autonomy, rational agents and agent architectures.
* **Block 2**: Data, information, knowledge and knowledge representation.
* **Block 3**: Ontologies, taxonomies, thesauri and folksonomies.
* **Block 4**: Semantic Web, Linked Data, RDF, RDF Schema, SPARQL and OWL.
* **Block 5**: Machine learning, data preprocessing, neural networks, K-Nearest Neighbor and Support Vector Machines.
* **Block 6**: Knowledge-based systems, expert systems, knowledge bases, working memory and inference engines.

## 🛠️ Data Contract & Logic

* **`sistemas_inteligentes (1).json`**: Contains the structured multiple-choice question bank, answer options, correct answers and quiz settings.

The current dataset contains **62 single-choice questions** from **2023 (A and B)** and **2025**.
