# quiz-si 🧠

Interactive self-assessment question bank for **Sistemas Inteligentes / Intelligence Systems**.

This repository contains a curated set of multiple-choice questions covering intelligent agents, knowledge representation, Semantic Web technologies, machine learning and expert systems.

The current question bank contains **62 single-choice questions**, including questions from **2023 (A and B)** and **2025**.

## 📚 Core Topics Covered

* **Intelligent agents:** autonomy, rational agents, reactive agents, model-based agents, goal-based agents and utility-based agents.
* **Agent-oriented programming:** differences between agents and objects, agent behaviour, context and collaboration.
* **Data, information and knowledge:** knowledge hierarchy, data quality, accessibility, integrity, precision and relevance.
* **Knowledge representation:** representation principles, taxonomies, thesauri, folksonomies and conceptual models.
* **Ontologies:** concepts, classes, axioms, domain ontologies, upper-level ontologies and ontology construction practices.
* **Semantic Web:** Semantic Web principles, Linked Data and semantic web mining.
* **RDF technologies:** RDF triples, URIs, RDF/XML, JSON-LD and RDF Schema.
* **OWL:** open-world assumptions, resource identification, restrictions and ontology representation.
* **SPARQL:** querying information represented using RDF triples.
* **Logic:** propositional logic and First-Order Logic.
* **Machine learning:** data preprocessing, training and testing data, noise identification and learning algorithms.
* **Learning algorithms:** Artificial Neural Networks, Self-Organizing Maps (SOM), K-Nearest Neighbor and Support Vector Machines.
* **Knowledge-based and expert systems:** advantages, limitations and main components of expert systems.
* **Expert system architecture:** knowledge base, working memory and inference engine.

## 🧠 Question Bank

The question bank is stored in:

* **`sistemas_inteligentes (1).json`**

Each question contains:

* A unique **`id`**
* A **`single_choice`** question type
* A set of possible **`options`**
* The question text in **`question`**
* The expected answer in **`correct_answer`**

The current collection includes:

* **18 questions** from `2023_A`
* **18 questions** from `2023_B`
* **26 questions** from `2025`

## 📖 Main Knowledge Areas

The questions focus especially on:

### Intelligent Agents

Agent autonomy, rational behaviour, prior knowledge, sensors and actuators, environment, objectives, performance measures and learning elements.

The question bank distinguishes between:

* Simple reflex agents
* Model-based reflex agents
* Goal-based agents
* Utility-based agents

### Knowledge Representation

Questions address the relationship between:

**Data → Information → Knowledge**

as well as different approaches to organizing and representing knowledge, including:

* Taxonomies
* Thesauri
* Folksonomies
* Ontologies

### Semantic Web and RDF

The question bank includes concepts related to:

* Semantic Web
* Linked Data
* URIs
* RDF
* RDF/XML
* JSON-LD
* RDF Schema
* SPARQL
* OWL

### Machine Learning

Covered concepts include:

* Data preprocessing
* Data normalization
* Noise identification
* Training and test datasets
* Artificial Neural Networks
* Self-Organizing Maps
* K-Nearest Neighbor
* Support Vector Machines

### Expert Systems

Questions cover both the characteristics of expert systems and their basic architecture:

* Knowledge base
* Working memory / fact base
* Inference engine

The question bank also includes advantages and limitations of expert systems and their relationship with knowledge engineering.
